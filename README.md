# Calculator

A responsive calculator built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Arithmetic: addition, subtraction, multiplication, and division
- Live result preview
- Percent, sign toggle, decimal, and backspace
- Recent calculation history
- Keyboard support (Enter to calculate, Esc to clear)
- Responsive layout with a glassmorphism-inspired design
- Safe expression parser (does not use `eval()`)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build tools required.

## Publish on GitHub
1. Sign in to GitHub and create a new **public** repository named `aurora-calculator`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Click **Commit changes**.
4. Your repository link will look like `https://github.com/YOUR-USERNAME/aurora-calculator`.
5. Optional: in repository **Settings → Pages**, deploy from the `main` branch and `/ (root)` to get a live demo.

Replace `YOUR-USERNAME` with your actual GitHub username. Do not submit a made-up repository URL; submit the real link after uploading.
